# WeildScanner

Приложение Qt/C++/OpenCV для обработки лазерного профиля V-образного сварного шва.

Модуль: `WeildProcessingPool` → `FrameWeildProcessing` → `WeildDetect`. Включены камера, видео и синтетический источник, метрическая обработка по калибровке, слежение, визуализация, JSONL и заглушка интерфейса робота.

Подробности алгоритма, схема классов, ограничения, формат калибровки и команды сборки: [документация модуля](docs/weild-module.ru.md).

Для демонстрации выберите **Источник → Синтетический V-шов** или запустите с `--synthetic`. Для физического датчика загрузите собственную калибровку камеры и лазерной плоскости. Проверка на реальной сварке и измерение производительности камеры необходимы отдельно.

Снимок архитектуры до внедрения модуля: [исходный анализ](docs/class-architecture.ru.md).
